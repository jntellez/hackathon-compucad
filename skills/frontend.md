# Frontend skill guidance

## Scope

Use these rules when modifying `apps/web`.

## Stack

- React
- Vite
- TypeScript
- TailwindCSS

## Rules

- Keep the UI simple and functional.
- Favor clarity over visual complexity.
- Prefer small, readable components.
- Avoid overbuilding the UI before the backend flow works.
- Use Tailwind utilities directly unless repetition becomes obvious.

## Initial UI areas

- Health status
- Collaborator selector
- Course list
- Active enrollments
- Simple agent chat panel

## Priority

The frontend should support the deterministic backend flow first. Visual polish is secondary to a stable demo.
